Hosting (GCP low-cost launch)
  • Backend: Cloud Run (min instances=0, 1 vCPU, 512–1024MB, us-central1).
  • Frontend: static build to Cloud Storage (≤5GB free); optional Cloudflare proxy for HTTPS/CDN (free).
  • Database: start with free Postgres (Railway/Supabase); plan move to Cloud SQL later (~$20–$40/mo smallest).
  • Email: SendGrid/Mailgun free tier via SMTP env vars.
  • Budget alerts in GCP; avoid Cloud SQL until ready to pay.
Month-1 est. with free DB: ~$0–$10 (egress/overages). With Cloud SQL: ~$20–$40/mo DB; Cloud Run/Storage likely near $0 at modest traffic.
